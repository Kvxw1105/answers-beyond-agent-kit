# Security policy

Do not open a public issue containing an API Key, card inventory, customer information, request payload, or unredacted screenshot.

Revoke an exposed Key immediately in the Answers Beyond member dashboard. Report vulnerabilities privately through GitHub Security Advisories for this repository and include only redacted reproduction steps plus request IDs.

The public kit intentionally excludes the production backend, database schema, deployment configuration, and operator credentials. Member authorization is enforced by the hosted API, not by local Skill text.
